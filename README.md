# Python Day 152 - Inventory Stock Management System

## Description
A Python-based inventory management application that helps manage shop products and stock quantities.

## Features
- View all available products
- Add new products
- Update product stock
- Sell products and calculate total price
- Identify low-stock products
- Save inventory data using JSON

## Files
- `inventory.py` - Main Python program
- `products.json` - Product inventory data

## Requirements
- Python 3.x

## How to Run
Keep both files in the same folder and run:

```bash
python inventory.py
```

## Concepts Used
- Python functions
- Lists and dictionaries
- JSON file handling
- Exception handling
- Conditional statements and loops
